# Message to students: project booking

> Sent before booking opens, and it now carries the link. Browsing is open immediately;
> the site refuses every booking until the instructor opens booking from the dashboard,
> so sharing the link early cannot give anyone a head start.

---

Subject: Project Booking Opens Soon, Important Instructions

Dear Students,

We are pleased to announce that we are opening projects for the Android Application Development program. Each of you will build one Android app that fetches live data from a free public API using Retrofit, and there are 25 projects to choose from.

How booking will work:

1. Every student has to book one project for themselves. Booking is done online at projects.humblecoders.in. You can open that link right now and read through all 25 projects, but booking will not be possible yet. The Book buttons stay switched off until booking officially opens, and they switch on by themselves at that moment, so you will not need to refresh the page or wait for another link.

2. Your personal booking code will arrive on your registered email from projects@humblecoders.in on the morning of booking day, a few hours before booking opens. Kindly check your spam folder as well, and do not share this code with anyone.

3. Each project can be taken by a maximum of 10 students, strictly on a first-come, first-served basis. Once a project is full, it cannot be booked.

4. Each student can book exactly one project, and the booking is final. We recommend shortlisting two or three projects in advance so you have a backup if your first choice fills up.

5. If you do not receive your code, or lose it, contact us and a new code will be issued. Only the most recently issued code is valid.

About the project report:

- The report has to be submitted in the college before the 20th, and must follow the format sent below. It is a fixed 4-page format.

- Only the first 2 pages (Part A: the front page and your project plan) have to be filled before submitting. You can submit the report with only this first part completed.

- The remaining pages (Part B) are to be filled once your project is done, before the final viva.

For any queries, feel free to reach out.

Best wishes,
Team Humble Coders

### Short reminder (for the moment booking opens)

Booking is now open at projects.humblecoders.in. If you already have the page open, the Book buttons are live, no need to refresh. Enter the code from your most recent email to confirm your seat. 10 seats per project, one project per student, first come, first served.
